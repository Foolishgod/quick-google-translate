# 划词谷歌翻译

**选中文字就能翻译，没有选区也能直接输入。阅读外文、中文写英文，都用一个浮窗完成。**

适用于 **Apple Silicon Mac · macOS 13 及以上**。

[下载最新版本](https://github.com/Foolishgod/quick-google-translate/releases/latest) · [查看版本记录](https://github.com/Foolishgod/quick-google-translate/releases)

## 特色功能

- **手动输入也能翻译**：没有选中文字时按快捷键，直接打开输入框。可粘贴、修改内容，点击“翻译”或按 `⌘ Return` 提交。
- **单词多释义**：输入单词时展示 Google 提供的常见释义，按词性分组，帮助理解不同用法。
- **一键中文 → 英文**：独立快捷键默认 `Option + Shift + 空格`，随时把选中的中文或输入的中文译成英文，两组快捷键都可自定义。
- **随选随译**：在网页、文档等可复制文字的软件中选中文字，按快捷键即可翻译，无需来回切换页面。
- **简洁磨砂浮窗**：原文与译文对照显示，跟随系统明暗外观；点击其他窗口自动收起，也可一键置顶，方便边看边用。
- **保留文字结构**：段落、列表、编号、缩进和代码换行尽量保持原样，长文更容易阅读。
- **快捷键由你决定**：默认 `Option + 空格`，可自定义 Control、Option、Command 等组合。选新文字再按直接换译文，同一文字与方向再按关闭，`Esc` 随时收起。
- **普通与高级翻译**：普通翻译无需登录或密钥；可选后台浏览器高级翻译（Gemini），无需安装扩展，登录后可在后台使用。
- **更新、卸载都在应用内**：一键检查更新，支持适用版本的增量包；卸载前可查看清理清单。

## 三步开始

1. **安装**：下载最新 Release 中的 `QuickGoogleTranslate-版本号.zip`，解压后将“划词谷歌翻译.app”拖到“应用程序”，再打开。
2. **授权**：前往“系统设置 → 隐私与安全性 → 辅助功能”，允许应用读取选中文字。
3. **翻译**：选中文字，按 `Option + 空格`；想中译英就按 `Option + Shift + 空格`。没有选区时直接在浮窗输入。按 `Return` 换行，`⌘ Return` 翻译，浮窗里可复制结果。

设置分为“翻译、快捷键、权限与维护”三个页面，可更改目标语言、翻译方式和两组快捷键。手动输入无需辅助功能权限。

应用尚未经过苹果公证。若系统阻止打开，请在“系统设置 → 隐私与安全性”中允许打开。

## 想用 Gemini 高级翻译？

先安装 Google Chrome，在应用设置选择“后台浏览器高级（Gemini）”并指定原文语言。打开专用登录窗口，登录 Google 并确认网页可使用高级模式，再点击“转入后台”。日常翻译只显示浮窗，专用浏览器资料与日常 Chrome 分开。

单词释义取决于 Google 返回的词典数据；查不到时仍显示正常译文。

高级模式为试用功能，真实 Google 登录与翻译流程仍待完整验证；能否使用取决于账号、地区、语言及 Google 的服务限制。

## 常见问题

- **无法取词？** 确认辅助功能授权并重新启动应用；若仍不可用，移除旧授权条目后重新添加“应用程序”中的当前应用。也可手动复制文字，从菜单栏选择“翻译剪贴板”。
- **快捷键冲突？** `Command + 空格` 和 `Control + 空格` 常被系统占用，可换一个组合，或在系统键盘设置中调整。
- **需要什么网络？** 需要能访问 Google，不支持离线翻译。图片、扫描 PDF 和无法复制的文字暂不支持。
- **如何更新或卸载？** 在菜单栏选择“检查更新…”，或到“设置 → 软件更新与卸载…”操作。非常旧的版本可先下载最新安装包手动替换。
