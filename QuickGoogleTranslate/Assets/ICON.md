# Application icon

Created with the built-in image generation tool for this application. `AppIcon.png` is the original image with transparency; `build-icon.sh` uses macOS tools to produce the packaged `AppIcon.icns` at standard sizes from 16 to 1024 pixels.

## Generation prompt

Use case: logo-brand
Asset type: production macOS translation application icon, square 1024x1024.
Primary request: create a refined, legible native macOS icon for a Chinese-English translation utility. A softly rounded square tile in rich blue with subtle frosted depth, containing two overlapping pale speech cards. The front card bears exactly the Chinese character 文 and the other card exactly the Latin letter A. Clear confident typography, restrained dimensional highlights, crisp contours, large simple forms recognizable at small sizes. Centered straight-on composition, generous safe margins, no perspective mockup, no extra words, no Google logo or trademark symbols. Fully transparent outside the rounded square tile, no background scene or checkerboard. A single finished icon.
