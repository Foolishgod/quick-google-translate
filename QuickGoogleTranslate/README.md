# 划词谷歌翻译 1.5.4

macOS 菜单栏工具。在 Chrome 或其他软件中选中文字、按快捷键，弹出简洁的原生浮窗。上方显示原文，下方显示译文，支持选择文字、复制译文和失败重试。

## 复用高级翻译页面（1.5.4）

保留同一个隐藏页面及高级模型选择，同一原文语言和目标语言组合下不再每次创建、加载、关闭页面。首次请求和语言切换加载空输入页面，确认高级模型后才提交文字。模型切换正常无需刷新，仅无法确认切换时进行一次兼容性重载；页面失效时最多重建一次。

每次输入前通过原生 textarea setter 和 input 事件清空旧文字，等待页面确认旧译文已消失，再填入新文字并等待高级译文稳定。不能确认清除时不接受旧结果，改用新页面恢复；不同原文得到相同译文也可正常处理。连续请求串行管理页面状态，通过请求标记取消旧页面脚本，并及时结束旧通信等待；旧结果不能覆盖新内容。关闭浮窗保留页面供下次使用，停止浏览器或打开登录窗口时清除页面状态。

模拟页面与原生控制器检查验证连续三次翻译零额外页面加载、语言切换、页面恢复、取消及迟到结果。另在真实 Chrome 中使用完全拦截的本地测试页面验证原生输入事件、切换模型、重复译文、多行文字和取消脚本；不使用 Google 账号或日常资料。真实 Google 登录和高级译文仍需在实际账号下验证，不能把本地模拟的时间视为 Google 服务速度。

## 根据选区切换翻译（1.5.3）

每次按快捷键都会重新读取当前软件的选中文字。浮窗隐藏时开始翻译；浮窗可见时，新选区内容与浮窗原文不同就直接替换翻译，内容相同才关闭。比较前只去掉首尾空白，不合并内部换行、不忽略大小写；比较的是文字内容，不是页面位置。未读到有效文字时保留当前译文并提示，Esc 和关闭按钮始终可以关闭。

新翻译会取消旧请求，迟到结果不覆盖新内容。快速连按时串行读取选区，只处理最新请求，避免复制兼容流程相互覆盖剪贴板；关闭浮窗会取消待显示结果及待处理选区，完成已发出的复制按键释放和剪贴板恢复。快捷键录入也会使未完成的取词失效。

原生 `--verify-selection` 检查使用受控选区和翻译回调，不联网、不更改剪贴板或权限；验证不同选区替换、同文关闭、空选区保留、迟到结果、快速连按、关闭后重新触发，以及取词未完成时进入快捷键设置。实际外部软件读取沿用辅助功能和复制兼容路径。

## 固定个人签名（1.5.2）

主应用与内置卸载工具使用同一份固定的本地代码签名证书。应用身份由证书指纹和 Bundle ID 共同确定，后续版本继续使用该身份，不再绑定每次构建的内容哈希。两份不同可执行程序已验证身份互相兼容；不同签名冒用同一 Bundle ID 会被拒绝。此前的临时签名版本切换到 1.5.2 时仍需重新授权一次；真实辅助功能权限跨更新保留仍需在授权后经过下一次更新确认，不能保证系统升级、权限重置等情形永不要求授权。

此证书用于个人自用，没有 Developer ID 或苹果公证，系统仍可能要求在“隐私与安全性”允许打开。安装位置保持在“应用程序”，从应用内检查更新。私钥由原生 Security API 直接生成并保存在构建机器的登录钥匙串中，不写入文件或公开仓库；Signing/identity.json 与 certificate.der 只包含公开证书资料。证书用于代码签名，不调整系统证书信任设置。

后续 build.sh 强制使用已固定的证书。证书或配置缺失、指纹不符时构建报错，不退回临时签名，也不自动换证书。新机器构建需单独规划身份迁移；不得重新生成身份并声称权限会保留。构建身份属于开发资料，应用卸载工具不会删除它。

## 快捷键修复（1.5.1）

支持录入 Control、Option、Command + 空格，也可在设置的“选择空格组合…”中直接选择。修复 Command 键等价事件遗漏与空格触发按钮动作的问题；重新选择当前快捷键不再与自身注册冲突。录入时退出设置或切换窗口会取消，注册失败保留原设置并尝试恢复原快捷键。

macOS 通常将 Command + 空格分配给 Spotlight、Control + 空格分配给输入法。应用通过公开系统接口检查已启用的快捷键冲突，不会修改系统设置；被占用时需先在“系统设置 → 键盘 → 键盘快捷键”中更改对应组合，再回到应用选择。其他软件占用时也会提示。

原生快捷键回归检查覆盖 AppKit 实际事件分发、Command 键等价路径、三种修饰键与空格、多修饰键、键盘重复、Escape、事件监听停止、重复录入与注册、冲突保留旧注册和解除冲突后的替换。测试不更改用户配置或系统快捷键。

## 应用内更新与卸载（1.5）

菜单栏新增“检查更新…”，设置新增“软件更新与卸载…”。使用 Sparkle 2.10.0，开启自动检查时通常每日检查一次，有新版本后由你确认安装。优先使用已发布且适配当前版本的差分包；版本不匹配或差分失败时改用完整包，仍由应用完成更新和重启，无需手动拖动替换。更新保留快捷键、语言、API 配置及专用浏览器的 Google 登录资料。

1.4 及更早版本未内置更新组件，需要手动安装一次 1.5。此后才能通过应用内更新。发布时必须递增 CFBundleVersion，保留旧发布归档，并运行 build.sh、release.sh；签署更新后发布 GitHub Releases 资产及 main 分支的 appcast.xml。在线更新源为 https://raw.githubusercontent.com/Foolishgod/quick-google-translate/main/appcast.xml，下载资产位于该仓库的 updates 发布。GitHub 网络不可用时会报连接错误，不影响已安装版本。

应用启用更新源与更新包的 Ed25519 签名校验，安装前校验更新包。私钥仅存于本机钥匙串，不进入应用或公开仓库。1.5.2 起使用固定个人签名，以保持更新前后应用身份一致；公开正式分发应使用 Developer ID 签名和公证。只读位置或系统写入权限限制可能阻止更新，更新组件会处理或报错。

“卸载此软件…”打开随应用内置的卸载界面，无需另下载工具。工具从独立临时位置启动，再列出应用、设置、缓存、浏览器登录资料和可选 Google Cloud 密钥；确认所选项目后执行。文件移入废纸篓，密钥永久删除，日常 Chrome 资料保留。辅助功能条目及曾手动安装的旧 Chrome 扩展仍需在各自设置中移除。临时卸载副本在关闭后清理，正在更新时无法同时卸载。

更新及卸载使用隔离副本验证，不会为了测试替换或删除现有安装。后台 Google 登录与高级译文的真实联网限制见下文。

## 无扩展的后台浏览器高级翻译（1.4 试用版）

使用本机安装的 Google Chrome 引擎，无需安装浏览器扩展。首次登录时打开一个专用 Chrome 窗口；完成后转为 Chrome 无窗口模式，日常只显示原生翻译浮窗。此版本没有把 Chrome 引擎打包进应用，需要先安装 Google Chrome。

1. 从菜单栏打开设置，选择“后台浏览器高级（Gemini）”，并设置原文语言和目标语言。原文语言默认 English，高级模式需要明确指定语言。
2. 点击“后台浏览器与 Google 登录…” → “打开登录窗口”。在出现的专用 Chrome 窗口中登录 Google，并确认 Google Translate 的“高级”模型可用。登录和验证码均由你在 Google 页面完成。
3. 回到设置点击“转入后台”。专用窗口会关闭，浏览器引擎继续无窗口运行。
4. 在任何可复制文字的软件中选中文字，按自定义快捷键。选新文字后再按会直接翻译；选中相同文字再按关闭浮窗，Escape 也可关闭。
5. 登录过期、出现验证或无法切换高级模型时，重新打开登录窗口处理，然后转入后台再试。

之前安装的配套扩展不再需要。1.4 首次启动会选择新后台浏览器模式，并显示设置。旧版本的连接码、语言和快捷键配置仍保留；旧 Chrome 账号会话不会导入新模式，需要在专用窗口重新登录。

专用浏览器资料保存在 `~/Library/Application Support/QuickGoogleTranslate/BrowserProfile`。此目录保存 Google 登录状态和网站偏好，与日常 Chrome 个人资料独立；应用不读取账号密码、不导出 Cookie。Google 和浏览器可能根据各自设置保存输入文字和访问记录。退出翻译应用会停止由它启动的浏览器；也可在设置中点击“停止后台浏览器”。停止后，再触发翻译会重新启动后台引擎。

后台通信使用本机 127.0.0.1 上的临时端口，仅用于控制专用浏览器。手动登录窗口不启用调试连接。Google 页面确认高级模型并输出稳定结果后，应用才显示译文；正常切换模型与同一语言组合的连续翻译不刷新页面。关闭浮窗会取消本次请求并忽略迟到的结果，但保留页面供下次使用。

**这是可试用的功能：已经编译，并通过模拟浏览器通信、模拟页面及真实 Chrome 中的本地页面检查；真实 Google 登录、会话在后台保留以及高级模型端到端翻译尚未验证。** Google 的模型支持取决于账号、地区、语言和页面变化；Google 也可能要求重新验证或限制自动化访问。应用不会绕过这些限制，失败时会显示错误并提示打开登录窗口。后台浏览器需要持续联网，并会占用一定内存。

如需普通模式，可在设置选择“Google 普通翻译”。Google Cloud 密钥与网站登录互相独立，后台高级模式不会调用 Cloud 计费接口。

## 快捷键开关和磨砂浮窗

同一个自定义快捷键：浮窗隐藏时读取选中文字并翻译；浮窗显示时，先重新读取选区，新内容直接替换翻译，相同内容才关闭。翻译请求尚未完成时也可切换新内容或选相同文字关闭。未能读取选区时保留原译文；Escape 和窗口关闭按钮可随时关闭并使未完成的取词与翻译失效。

窗口采用 macOS 原生 NSVisualEffectView 的 behind-window 模糊和 popover 材质。窗口背景透明，文字保持完整不透明；带圆角、柔和阴影以及半透明的原文与译文卡片。跟随系统明暗外观。若 macOS 的“减少透明度”开启，系统会调整视觉材质，可能呈现更实的背景。

原生界面检查已验证：窗口材质与透明属性、布局约束、同文快捷键关闭、新选区替换、关闭后取消结果、Escape、关闭按钮和重复显示后关闭。预览使用固定示例，不代表联网翻译结果。预览图只呈现内容布局，实际屏幕上背景模糊会随窗口后方的内容变化。

## 安装更新

1. 从菜单栏退出旧版本。
2. 解压 `dist/划词谷歌翻译.zip`，将“划词谷歌翻译.app”放入“应用程序”，替换旧应用，再打开。当前构建支持 Apple Silicon，macOS 13 或更新版本。
3. **从 1.5.1 及更早版本切换后重新授权辅助功能**：系统设置 → 隐私与安全性 → 辅助功能，关闭并重新开启此应用。如果仍不可用，移除旧条目后用“+”重新添加“应用程序”中的新版。
4. 回到 Chrome，在网页中选中可复制的单词或句子，按 **Option + 空格**。更改过的快捷键和目标语言会保留。
5. 从菜单栏气泡图标 → 设置，点击快捷键按钮、按下新组合。必须包含 Command、Control 或 Option；Escape 取消。目标语言可选简体中文、繁体中文、英文、日文、韩文、法文、德文或西班牙文。
6. 浮窗中点击“复制译文”可复制结果；按 Escape 或关闭按钮隐藏浮窗。网络失败时可点击“重试”。

本地构建使用固定个人代码签名证书，没有 Developer ID 和苹果公证。系统阻止打开时，可在系统设置 → 隐私与安全性中允许打开此应用。

## 开关已开启，仍然提示未授权

从旧的临时签名切换到个人签名、改变运行副本或系统权限被重置后，系统可能保留旧版本或另一运行路径的授权条目。只看系统设置开关，不能确认当前运行进程的授权。此版本使用系统授权请求，并在信任标记为否时尝试通过系统实际允许的外部控件读取确认权限；不会修改系统授权数据库。

1. 从菜单栏退出所有翻译应用副本。
2. 在系统权限页面选中旧的 QuickGoogleTranslate 和“划词谷歌翻译”条目，用底部“−”移除这两个应用条目。
3. 将新版放到“应用程序”文件夹，只从该位置打开。
4. 在新版设置点击“申请读取权限”。在系统页面用“+”添加“应用程序”中的新版并启用。
5. 重新打开应用，再回到原软件选中文字测试。

设置页显示当前应用路径，并提供“显示当前应用位置”和“重新启动应用”。若检测到另一个副本在运行，新副本会提示退出原副本后重试。

1.5.2 起保持个人签名身份稳定，目标是沿用更新前授权；已验证签名身份跨版本一致，辅助功能授权跨真实更新保留仍需在用户电脑上确认。

## Chrome 兼容

此版本增加了 Chrome / Chromium 的辅助功能启用、短暂等待、网页文字选区标记读取以及父控件查找。直接读取失败时，等待快捷键完全松开，再向原来的软件发送完整的 Command-C 组合，最多等待约两秒。

如果仍然无法读取，请先确认新版的辅助功能权限，然后在 Chrome 手动按 Command-C，再从菜单栏选择“翻译剪贴板”。若 Chrome 本身无法复制该内容，工具也无法读取。

复制兼容会尝试恢复原剪贴板数据，并避免覆盖读取后发现的后续变更；大型、延迟提供的数据或并行复制仍可能无法完整恢复。密码输入控件不执行翻译。图片、扫描 PDF、游戏画面以及禁止复制的内容不支持。

## 普通翻译连接

普通翻译日常只显示原文和译文浮窗，无需登录。

选择“Google 普通翻译”时，无需密钥：先尝试 Google 的免认证文字端点；连接失败时，在后台加载官方 Google Translate 网页并提取结果。Google 未承诺免认证端点或网页结构的稳定性，可能限流、要求 Cookie 确认或更改页面。后台网页方式未完成联网成功验证，因此不能保证免密钥模式始终可用；失败时会显示可重试的错误。

如果免密钥方式持续失败，可在设置 → “Google Cloud 连接（可选）”填入已启用 Cloud Translation Basic 的 API Key，改为官方接口。密钥保存在 macOS 钥匙串，费用和配额由你的 Google Cloud 项目决定。清空并保存即可恢复免密钥模式。

需要能访问 Google 的网络；本应用不提供代理或离线翻译。Google Cloud 的密钥和成功请求未在此环境中验证。

只在你触发翻译时发送所选文字。应用不另存翻译历史；普通模式的备用网页使用临时存储，后台浏览器高级模式使用专用持久化资料保存登录状态。默认连接的文字出现在 HTTPS 请求 URL 中；官方接口使用 HTTPS POST。一轮最多 5,000 字符。

已检查源码编译、翻译文本处理、原生浮窗的布局约束及安装包。自动检查也覆盖权限确认、实际读取成功、拒绝访问及无法确认的状态；覆盖空选区、字符长度、中文和特殊字符的 URL 编码、多句译文拼接、官方译文中的 HTML 实体以及异常响应。

原生界面布局检查及内容截图使用固定示例文字，不代表已成功联网翻译；桌面后方的动态模糊效果仍需要在你的 Mac 上确认。需要在你的 Mac 授权后验证真实 Chrome 选区读取及翻译；这些端到端行为尚未在此环境中验证。

## 从源码构建

在本目录执行：

```sh
zsh build.sh
```

需要 Apple Command Line Tools、随项目固定版本的 Sparkle 框架、相邻目录中的卸载工具源码，以及 Signing/identity.json 对应的钥匙串签名身份，无需完整 Xcode。脚本构建 arm64；Intel Mac 可将 target 改为 `x86_64-apple-macosx13.0` 后重建。保持相同个人签名身份；更换身份后仍需重新授权辅助功能。
