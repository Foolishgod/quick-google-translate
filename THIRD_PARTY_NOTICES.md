# Third-party components

- [Sparkle 2.10.0](https://github.com/sparkle-project/Sparkle/releases/tag/2.10.0): downloaded by `QuickGoogleTranslate/setup-dependencies.py` from the official release with a pinned SHA256. Its license is preserved at `licenses/Sparkle-LICENSE.txt` and copied into built applications. Downloaded frameworks and tools are not committed.
- [ws](https://github.com/websockets/ws): MIT-licensed, development-only dependency used by the simulated browser test. Its registry URL and integrity are pinned in `package-lock.json`. npm preserves the package license when installing it. It is not bundled into the macOS translating application.

No project-wide source license has been selected yet. Third-party components retain their own licenses.
