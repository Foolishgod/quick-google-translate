# 划词谷歌翻译

macOS 划词翻译工具。选中文字、按自定义快捷键，用简洁的磨砂浮窗查看原文和译文；再按一次关闭。

本仓库仅用于发布应用安装包、签名更新源和使用说明。支持 Apple Silicon、macOS 13 或更新版本。

## 安装

从 [发布页](https://github.com/Foolishgod/quick-google-translate/releases/tag/updates) 下载最新的 QuickGoogleTranslate 安装包，解压后将“划词谷歌翻译.app”放到“应用程序”。旧版用户请先退出应用再替换一次。1.5.2 起使用固定的个人代码签名证书，没有苹果公证。系统阻止打开时可在“系统设置 → 隐私与安全性”允许打开。

在系统设置的辅助功能页面授权应用。默认快捷键为 Option + 空格，可在设置更改。开关已开启却无法读取时，请移除旧条目，再添加当前新版并重新启动应用。

## 个人签名与辅助功能

1.5.2 开始固定代码签名身份，减少每次更新因应用身份变化导致辅助功能授权失效的问题。签名私钥只存在于构建机器的钥匙串，发布包只带公开证书和签名。不需要 Apple Developer 会员，应用尚未经过苹果公证，仍可能需要手动允许打开。

首次切换此版本：更新后退出应用，在系统的辅助功能（或 Device Control and Data Access）页面移除旧条目，再添加“应用程序”中的新版并重新打开。之后保持该安装位置并通过应用内更新。

## 快捷键设置

1.5.1 修复了 Control、Option、Command + 空格无法录入的问题。可点击快捷键录入，也可在“选择空格组合…”中直接选择；重复设置同一组合不会报错，冲突时保留原快捷键。

Command + 空格通常被 Spotlight 占用，Control + 空格通常被输入法占用。若应用提示系统冲突，请先到“系统设置 → 键盘 → 键盘快捷键”关闭或更改对应组合，再回到应用选择。应用不会自动更改系统快捷键。

## 更新与卸载

1.5 起支持应用内更新：菜单栏点击“检查更新…”或在设置进入“软件更新与卸载…”。发布适配当前版本的差分包时优先下载增量；否则使用完整包，均由应用自动安装和重启。更新源及安装包经过签名验证。

1.4 及更早版本没有更新组件，需先安装一次 1.5。从 1.5.1 及更早版本切换到个人签名版时，请重新授权一次辅助功能。后续版本将保持证书和应用标识一致，目标是继续沿用授权；身份跨版本一致已验证，权限跨真实更新保留仍需在授权后的更新中确认。系统升级或权限重置等情况仍可能需要重新授权。

卸载已内置：设置 → 软件更新与卸载 → 卸载此软件。确认清单后清理应用及残留。文件移入废纸篓；Google Cloud 密钥如勾选会永久删除。辅助功能条目仍需在系统设置手动移除。

## 后台高级翻译

本机需要安装 Google Chrome，无需扩展。设置选择“后台浏览器高级（Gemini）”并指定原文语言；打开专用窗口登录 Google，确认网页高级模式可用，再点击“转入后台”。随后浏览器无窗口运行，只显示翻译浮窗。账号需要验证时，再打开专用登录窗口处理。

使用独立的浏览器资料目录，不导入日常 Chrome 账号，不读取密码。Google 登录、后台会话及高级译文的真实端到端流程尚未在开发环境验证，属于试用功能。Google 可根据账号、地区、语言和自动化访问情况限制使用。普通翻译也需能访问 Google 的网络。

第三方更新框架 Sparkle 的许可随应用附带。本仓库不包含账号资料、API 密钥或更新签名私钥。
